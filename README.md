# Smart RAG AI

AI-powered document question-answering system using RAG, Llama 3.2, Ollama, FAISS, and Streamlit.

## Features
- Document-based question answering
- FAISS semantic search
- Local Llama 3.2 model
- Multi-turn chat
- Streamlit interface

## Tech Stack
Python, Streamlit, Ollama, Llama 3.2, FAISS, LangChain
